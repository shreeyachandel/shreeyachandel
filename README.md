# Hi, I'm Shreeya Chandel

I am an AI and software engineer with an MSc in Artificial Intelligence for
Biomedicine and Healthcare from UCL. I enjoy building products that make
complex systems easier to understand, whether that means an interactive logic
simulator or a machine-learning pipeline for medical imaging research.

## Selected work

### [Predicting Retinal Sensitivity from OCT](https://github.com/shreeyachandel/retinal-sensitivity-prediction)

An end-to-end multimodal machine-learning project aligning OCT imaging with
pointwise microperimetry. The repository includes the full dissertation,
research pipeline, aggregate results, tests, and a runnable synthetic-data
demonstration.

**Python · scikit-learn · pandas · NumPy · medical imaging · grouped validation**

[Run the notebook in Colab](https://colab.research.google.com/github/shreeyachandel/retinal-sensitivity-prediction/blob/main/notebooks/retinal_sensitivity_demo.ipynb)
· [Read the dissertation](https://github.com/shreeyachandel/retinal-sensitivity-prediction/blob/main/output/pdf/public-thesis.pdf)

### [Logidex](https://github.com/shreeyachandel/logidex)

An interactive logic-gate simulator for building circuits, translating Boolean
expressions into diagrams, and following computations step by step.

**React · JavaScript · Python · interactive visualisation**

[Open the live application](https://logidex-one.vercel.app/)
